Mera AA-MD-Bot project (WhatsApp bot, Node.js, Baileys, MongoDB) Replit se Oracle Cloud VM par deploy karte waqt kai errors aa rahe hain. In sab ko permanently fix karo taake future mein clean deploy ho:

1. package-lock.json mein kuch packages (jaise youtube-po-token-generator) ke "resolved" URLs Replit ke internal proxy (package-firewall.replit.local) ke saath save ho gaye hain. Ye sirf Replit ke andar resolve hota hai, bahar (Oracle VM, ya kisi bhi external server) par npm install fail karta hai with error: "getaddrinfo EAI_AGAIN package-firewall.replit.local". Fix: package-lock.json ko regenerate karo taake sab dependencies ka resolved URL public npm registry (https://registry.npmjs.org/) ka ho, Replit-specific proxy ka nahi. Koi .npmrc file bhi check karo jo custom registry point kar rahi ho aur use hata do ya default npmjs registry par set karo.

2. Repo ka structure confusing hai — root folder (AA-MD-Bot) mein sirf wrapper files hain (.replit, replit.md, scripts/) aur asal bot code (package.json, index.js, ecosystem.config.cjs, plugins/, lib/) ek nested "AA-MD-Bot/AA-MD-Bot" subfolder ke andar hai. Ye deploy karte waqt confusion create karta hai kyunke deploy/setup.sh script root folder mein npm install chalati hai jahan koi package.json hi nahi hai. Fix: ya to bot code ko root mein move karo (flatten structure), ya phir deploy/setup.sh script ko update karo taake wo sahi nested BOT_DIR path use kare.

3. .env.example mein MONGODB_URI ka format sirf placeholder example deta hai (mongodb://user:pass@10.0.0.X:27017/...) — koi clear guide nahi hai ke agar main apna khud ka MongoDB server (dusre VM par) use kar raha hun to authSource, user creation, aur network/firewall (port 27017) setup kaise karna hai. Fix: .env.example mein comments add karo jo step-by-step batayein: (a) MongoDB VM par user kaise banayein, (b) authSource kya hona chahiye, (c) firewall/security list mein port 27017 allow karna zaroori hai.

4. Deploy script (deploy/setup.sh) ka Step 8 "Node.js Dependencies" kabhi complete hue bina silently ruk jata hai jab galat directory mein chalaya jaye — koi clear error message nahi deta ke "package.json yahan nahi mila, sahi path ye hai". Fix: script mein error handling add karo jo directory verify kare aur clear message de agar package.json na mile.

5. Bot start hone par "MongoDB init failed, starting with empty cache: Authentication failed" — matlab agar .env mein galat/placeholder MongoDB credentials hon to bot silently empty cache ke sath chal jata hai bina kisi clear warning ke ke database features (session persistence, settings) kaam nahi karenge. Fix: startup par ek clear, visible warning print karo agar MongoDB connect na ho paye, jisme bataya jaye ke kaunse features disabled rahenge.

Sab fixes ke baad ek clean, working "deploy.sh" script bhi bana do jo kisi bhi fresh Ubuntu VM (Oracle Cloud ya kahin bhi) par ek hi baar chalane se: system dependencies install kare, sahi bot directory mein npm install kare (public registry se), .env.example se .env banaye, aur PM2 ke through bot start kare — bina kisi manual intervention ya dobara error ke.
