🔀 Bot Mode — Private / Public
🔒
Private Mode
Only You (self-chat) can use commands. Perfect for personal use — no one else can trigger the bot.
.mode private
🌐
Public Mode
Everyone can use commands — any number that messages the bot gets a response. Current default.
.mode public

💡 In Private mode, only your "Message yourself" (You) chat responds to commands. Click a card to copy the command.
