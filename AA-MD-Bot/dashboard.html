🎵 Play Audio — .play / .song

Search by name or paste a YouTube URL. Bot shows info card (title, duration, thumbnail) then sends the MP3. .play and .song are identical.

🔀 Bot Mode — Private / Public
🔒
Private Mode
Only You (self-chat) can use commands. Perfect for personal use — no one else can trigger the bot.
.mode private
🌐
Public Mode
Everyone can use commands — any number that messages the bot gets a response. Current default.
.mode public

💡 In Private mode, only your "Message yourself" (You) chat responds to commands — great for personal automation. Click a card to copy the command.
